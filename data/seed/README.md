# Seed corpus

The chat assistant answers **only** from the files in this directory. Nothing here is
generated by the model at request time, which is what makes the Evidence Panel citations real.

| File | Feeds |
|---|---|
| `knowledge.json` | retrievable chunks + their source URLs (the `documents` / `chunks` tables) |
| `standards.csv`  | the `standards` table (Find Standard) |
| `forms.csv`      | the `forms` table (Forms Hub) |

## Every record carries a `verified` flag

`verified: false` means *a human has not yet checked this against the official BIS source*.
Unverified chunks are still retrievable, but any answer that leans on one is capped at
`confidence: "unverified"` and the response carries a warning. Verify a record by opening its
`source_url`, confirming the text, and flipping the flag to `true`.

**Do not demo with unverified records.** Wrong IS numbers in a compliance tool are worse than
no answer — the refusal path (`RELEVANCE_THRESHOLD` in `.env`) exists so the assistant says
"I don't have a source for that" instead of guessing.

## Adding a record

Append to the JSON/CSV and re-run the loader; it upserts on `source_url` + `heading`:

```bash
python -m ingestion.load_seed
```
