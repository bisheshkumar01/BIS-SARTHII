# Runtime dependencies for the API and the chat path.
#
# Kept deliberately slim: Vercel's Python builder installs from the requirements.txt it finds,
# and its unzipped function limit is 250 MB. The vision/RAG stack (torch, faiss, easyocr,
# opencv) is an order of magnitude past that, so it lives in requirements-ml.txt and is
# installed only for local work — never shipped to the function.
#
# Python 3.11 or 3.12. Not 3.14: pydantic-core has no cp314 wheel, so pip falls back to
# building it from Rust source and fails.
#   py -3.11 -m venv .venv
#   .venv/Scripts/pip install -r requirements.txt
